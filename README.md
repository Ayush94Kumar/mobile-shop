# Indian Communication — Mobile Shop (mobile-shop)

**Indian Communication** is a simple, responsive static website for a mobile & electronics retail shop.  
Built with plain **HTML**, **CSS** (split into small files) and **JavaScript** (product rendering + filters). Perfect for a beginner project or a small business landing page.

**Live demo:** https://ayush94kumar.github.io/mobile-shop/

---

# 🚀 Features

- Responsive, single-page layout (Home / Products / Gallery / Contact)
- Products auto-rendered from a JavaScript array (`js/products.js`)
- Category filters: All / Mobiles / Electronics
- Split CSS files for easier maintenance (header, navbar, products, etc.)
- Mobile-friendly navbar with hamburger menu
- Clean, modern design using a site-wide theme
- Easy to edit content and add new products/images
